# Investment Intelligence Hub Architecture

Date: 2026-06-07

## Purpose

The Investment Intelligence Hub is a unified information distillation layer for the current investing research workflow.

It is designed to integrate three input sources:

- Existing daily pre-market stock analysis reports from `ai-investing-monitor/`
- ljg-Invest style deep investment analysis reports
- User-captured X posts and X long-form articles converted into readable Markdown/HTML links

The hub should distill these inputs into research signals, thesis impacts, watchlist impacts, source provenance, and follow-up questions.

## Source Hierarchy

The Hub uses a tiered source policy so discovery, daily context, deep research, and primary verification do not get mixed together.

| Tier | Source Class | Examples | Default Source Quality | Allowed Use | Boundary |
|---|---|---|---:|---|---|
| Tier 1 | Primary Sources | Company IR, earnings releases, earnings call transcripts, SEC filings, investor presentations, official guidance/orders/backlog/capex disclosures | 0.85-0.95 | Confirm or reject claims; support durable investment thesis and memory proposal after human review | Phase 8 may add a primary-source registry; Phase 7A does not create it. |
| Tier 2 | Daily Base / Core Financial News | Daily report, Yahoo Finance, CNBC, price/volume/news context | 0.65-0.80 | Daily context, `risk_review`, `monitor`, `verify`, follow-up tasks | Cannot alone update durable thesis without Tier 1 confirmation or explicit human approval. |
| Tier 3 | ljg-invest Deep Research | `ljg-invest` reports and deep-dive notes | 0.60-0.75 | Periodic thesis baseline, speculation thesis, `thesis_review`, verification tasks | Not a daily required input; cannot confirm durable thesis without Primary Source verification. |
| Tier 4 | User-Captured X Posts | Files manually captured into `investment-intelligence-hub/inbox/x_posts/` | 0.40-0.60 | Discovery, narrative awareness, idea generation | Must be `needs_corroboration` unless confirmed by Tier 1 or Tier 2; cannot support durable thesis alone. |

X content is treated as discovery and narrative awareness, not final truth.

## X Input Boundary

The only X input supported for now is user-captured X posts.

The Hub curated inbox is:

```text
investment-intelligence-hub/inbox/x_posts/
```

The existing `x-to-markdown/` path may remain as a compatibility or conversion-output path, but it is not the curated Hub inbox. Phase 7A does not implement Readwise, X bookmarks API, X timeline fetching, or followed-account scraping.

## Production Workflow Boundary

The existing `ai-investing-monitor/` production workflow remains preserved.

The hub does not replace or rewrite:

- `ai-investing-monitor/scripts/run_daily_report.py`
- `ai-investing-monitor/scripts/build_report.py`
- `ai-investing-monitor/scripts/build_html.py`
- `ai-investing-monitor/config/watchlists.yaml`
- `ai-investing-monitor/config/themes.yaml`
- Existing daily reports
- Existing ljg-Invest reports
- Existing X converted Markdown/HTML files

During the initial migration, the hub reads or references existing outputs only after they are already generated by the current workflow.

## Non-Goals

The hub is not a trading system.

It must not:

- Connect to brokerage accounts
- Create orders
- Execute trades
- Add trading automation
- Generate buy/sell instructions
- Generate position-size changes
- Treat X posts as confirmed facts without corroboration

## Target Output

The target output is a research-only daily intelligence brief that answers:

- What changed across sources?
- Which signals have source-backed evidence?
- Which signals affect durable investment theses?
- Which signals are speculative or unverified?
- Which tickers or themes need verification?
- Which items are likely noise or hype?

Action labels are research workflow labels only, such as `verify`, `monitor`, `thesis_review`, `risk_review`, `ignore_noise`, and `weekly_review_candidate`.
